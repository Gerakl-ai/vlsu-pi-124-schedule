# Лад · ПИ-124

Mobile-first PWA для расписания ПИ-124, ИИТЭ, ВлГУ и личных умных заметок.

## Возможности

- живое расписание ВлГУ с cache-first запуском и offline reload;
- экраны «Сегодня», «Неделя», «Записи» и «Настройки»;
- четыре авторские темы и собственная тема с настройкой фона, текста, акцентов и поверхностей;
- rich-text редактор заметок с заголовками, чек-листами, цветом текста, выделением, цитатами и списками;
- автосохранение черновиков, голосовой ввод и прикрепление масштабируемых фотографий;
- локальная классификация по контексту, пользовательские папки и автоматическая привязка домашних заданий к предметам;
- адаптивная компоновка для портретного и горизонтального положения телефона;
- опциональное AI-уточнение классификации через Cloudflare Workers AI;
- локальные напоминания, PWA manifest, service worker и резервная копия записей.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Приложение откроется на `http://127.0.0.1:5173/`.

## Cloudflare Workers

Рекомендуемый вариант деплоя, потому что он поддерживает прокси ВлГУ и Workers AI:

```bash
pnpm build
npx wrangler deploy
```

`wrangler.jsonc` публикует `dist`, направляет `/vlsu-api/*` и `/app-api/*` через `src/worker.ts`, а также подключает binding `AI`.

## Cloudflare Pages

Pages остаётся совместимым вариантом для расписания:

```text
Build command: pnpm build
Build output directory: dist
```

`functions/vlsu-api/[[path]].ts` проксирует API ВлГУ. Локальная сортировка записей продолжит работать, но облачное AI-уточнение требует Worker route `/app-api/classify`.

## Уведомления

Локальное напоминание работает, пока браузер может выполнить запланированный код. Для гарантированной доставки при полностью закрытом приложении нужен Web Push: установленная на экран «Домой» PWA, push subscription и серверный отправитель. Service worker уже умеет принимать push-события, но серверная регистрация подписок в эту локальную версию не входит.

## Данные и приватность

Расписание кэшируется локально. Записи, пользовательские папки, черновики и вложенные изображения хранятся в IndexedDB текущего устройства. Cloudflare AI выключен по умолчанию и включается отдельно в настройках; базовая классификация всегда работает локально.
